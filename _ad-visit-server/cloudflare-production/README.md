# 운영용 Cloudflare 광고 방문 수집기

기본 설정에서 수집 API는 404를 반환합니다. 운영 홈페이지는 이 API에 연결되어 있지 않습니다. 별도 운영용 D1을 사용하고, 가상 IP 테스트용 Worker, D1 및 테스트 키를 재사용하지 않습니다.

활성화 전 사무소가 수집·이용 및 국외이전 근거, 이전 국가·수탁자 및 처리방침 내용을 확인합니다. 동의를 근거로 하는 경우 필요한 동의 화면과 거절 경로를 구현하고 검증한 후 활성화합니다. D1 복구본과 Cloudflare 서비스 로그의 저장 위치 및 잔존 기간도 확인합니다. 7일은 검토용 기본값입니다. 운영 행 삭제는 15분마다 실행되며 D1 복구본의 삭제 시점과 구분됩니다.

배포 시 운영 D1 ID를 설정하고 schema.sql을 적용합니다. Worker 이름과 D1 이름은 huseong-ad-visit입니다. 테스트에는 로컬 Cloudflare 실행 환경과 가상 데이터를 사용합니다. 운영 계정에서는 비활성 상태에서 접근 차단과 D1 설정을 확인합니다. 공개 조회 API는 없으며 관리자가 Cloudflare D1 콘솔에서 조회합니다. 실제 수집은 처리 기준과 배포 권한이 확인되고 수집 URL을 기존 페이지에 설정한 뒤에만 시작합니다.
